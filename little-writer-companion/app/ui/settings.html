Privacy

  • Writing, projects, and the save stay on this computer. The app contacts GitHub only when Check for update is pressed, to read the latest release number, and sends none of that data. It does not download the update. On Windows, the WebView2 runtime it uses may contact Microsoft for runtime updates, independently of this app.
  • Only keystroke counts are kept. The key's position code is checked in memory (letter key or not) and then discarded. The text you type is never recorded. While Buddy is asking about a game, Y and N are noted as yes or no and then discarded. On Windows those two keys stay out of the document. They are never saved or logged.
  • No per-key timestamps are stored, only a total per day.
  • Window titles are read only to spot distractions and to ignore this app's own windows when a game is offered. They are never saved or logged.
  • Media detection reads only playing/paused. Scroll detection counts wheel ticks only.
  • “Pause listening” in the tray stops all counting.
  • When the timer finishes, the active window's rectangle is kept in memory so Buddy can walk to that monitor. A focus game reads the cursor only while it is playing. The ready click and a tag click land on Buddy. None of this is saved.
  • Data: state.json in the app data folder; fan letters as .md files in your journal folder. Supporter hats and games are read from a packs folder next to state.json. The app does not download them. Uninstalling keeps your data unless you tick “delete application data”.
