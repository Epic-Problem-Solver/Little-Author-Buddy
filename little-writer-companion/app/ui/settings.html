Writing

A word counts when Space, Enter, or Tab follows a letter or a digit. A hyphen or an apostrophe stays inside the word. Backspace shortens the word you have not finished. The app keeps that length as a number and drops it when you quit. It never keeps the letters.

    Privacy

    • Writing, projects, and the save stay on this computer. The app contacts GitHub only when Check for update is pressed, to read the latest release number, and sends none of that data. It does not download the update. On Windows, the WebView2 runtime it uses may contact Microsoft for runtime updates, independently of this app.
    • Only word counts are kept. Each key is classified in memory, then discarded. The text you type is never recorded. An unfinished word is a number, and it is not saved.
    • No per-key timestamps are stored, only a total per day.
    • Window titles are read only to spot distractions and to ignore this app's own windows when a game starts. They are never saved or logged. After fifteen minutes of writing at the desk, Buddy suggests a game. That suggestion is not saved. Falling asleep, wandering, or watching starts the wait over.
    • Media detection reads only playing/paused. Scroll detection counts wheel ticks only.
    • “Pause listening” in the tray stops all counting.
    • A game reads the cursor only while it is playing. A tag click lands on Buddy during play. Nothing about the game is saved.
    • Data: state.json in the app data folder; fan letters as .md files in your journal folder. Supporter hats and games are read from a packs folder next to state.json. The app does not download them. Activate copies a zip already saved on this computer. Uninstalling keeps your data unless you tick “delete application data”.
