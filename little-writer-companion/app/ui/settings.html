Only letter keys A–Z count toward words (by key position, so any layout and IME composition on letter keys work). Digits, punctuation, Space, Enter, Backspace, Tab, Delete, modifiers, function keys, arrows and the numpad never count.

Privacy

  • Everything stays on this computer. The app itself makes no network requests. On Windows, the WebView2 runtime it uses may contact Microsoft for runtime updates, independently of this app.
  • Only keystroke counts are kept. The key's position code is checked in memory (letter key or not) and then discarded; the text you type is never recorded.
  • No per-key timestamps are stored, only a total per day.
  • Window titles are read only to spot distractions and are never saved or logged.
  • Media detection reads only playing/paused. Scroll detection counts wheel ticks only.
  • “Pause listening” in the tray stops all counting.
  • Data: state.json in the app data folder; fan letters as .md files in your journal folder. Uninstalling keeps your data unless you tick “delete application data”.
