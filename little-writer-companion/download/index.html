The writing companion for Windows, Mac, and Linux.

Little Author Buddy runs on a computer, not on a phone or tablet.

Which computer are you on?

Download for Windows

If Windows says it protected your PC, choose More info, then Run anyway.

Show the steps
  1. Open the downloaded setup file.
  2. If a blue window says Windows protected your PC, choose More info, then Run anyway.
  3. If a WebView2 installer appears, let it finish. Little Author Buddy is then in the Start menu.

The file is named Little-Author-Buddy_0.6.2_x64-setup.exe. That is the official copy.

Download for Mac

Mac will block the first open. Click Done. Do not move it to the Trash.

Works on Intel and Apple silicon Macs.

Show the steps
  1. Open the downloaded disk image. Drag Little Author Buddy into Applications. Open it from Applications.
  2. When Mac says it cannot verify the app, click Done.
  3. Apple menu, System Settings, Privacy & Security. Scroll to Security. Click Open Anyway, then confirm. If the button is missing, open the app again and come straight back.
  4. On that same page, allow Little Author Buddy under Accessibility, and under Input Monitoring if it is listed. Open the app again.

On macOS Sonoma or earlier, Control-click the app and choose Open.

The file is named Little-Author-Buddy_0.6.2_universal.dmg. That is the official copy.

Download for Ubuntu and Debian

Open the download. Ubuntu will offer to install it.

Other Linux. Make that file executable, then open it. The computer also needs WebKitGTK 4.1.

Show the steps
  1. Open the downloaded file.
  2. Ubuntu will ask to install it. Confirm. Little Author Buddy then appears with your applications.

The file is named Little-Author-Buddy_0.6.2_amd64.deb. That is the official copy.
