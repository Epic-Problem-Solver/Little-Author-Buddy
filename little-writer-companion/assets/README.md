# Little Author Buddy — character assets (v0.7)

Files: `character.svg` (the full character and desk scene), `desk.svg` (the desk and tool on their own, same geometry), `lw-character.css` (colours, states and animations), `lw-color.js` (`lwApplyColor` fallback), `ui-close.svg`, `ui-gear.svg`, `preview.html` (generated by `build_preview.py`), `preview.png`.

Inline the SVG markup in the DOM; an `<img>` tag won't pick up CSS variables or state changes. Load `lw-character.css`, and `lw-color.js` if you need the colour fallback. The SVG is 240×220.

## State API
`<svg class="lw-char" data-face="…" data-body="…" data-tool="…" data-side="right|left" data-dir="left">`. Change the attributes to switch state; face and body are independent.

| data-face | meaning (SPEC trigger) |
|---|---|
| `idle` (default) | smile, periodic blink |
| `blink` | rapid blinking |
| `focused` | typing: narrowed eyes scanning, flat mouth |
| `sleepy` | drooping eyes, yawn |
| `asleep` | closed eyes + floating Zzz (stays readable when mirrored) |
| `curious` | watching a distraction / peeking |
| `excited` | race back on the first keystroke |
| `proud` | project complete |
| `shy` | hiding |

| data-body | meaning |
|---|---|
| `idle` (default) | gentle breathing |
| `typing` | **desk scene**: buddy behind the desk, beside the tool; types / writes |
| `sleeping` | **desk scene**: slumped toward the tool; hands hidden behind the desk; quill rests in the inkwell |
| `away-from-desk` | **desk scene, buddy hidden**: only the desk and tool (quill in the inkwell). Same as `desk.svg` |
| `walking` | waddle; hand layering follows `data-dir` |
| `rushing` | v0.7 run: leans into the direction of travel, both hands stream out **behind** and flutter |
| `racing` | legacy run (kept working): bouncy lean with hands pumping at the sides |
| `peeking` | leans in and out from the right edge (host clips along the window/screen edge) |
| `watching` (alias `away`) | back view, face hidden; subtle tilt and lean-in, as if watching a video |

| data-tool | desk scene tool (laptop is the default when absent or unknown) |
|---|---|
| `laptop` | open lid faces away from the viewer at the desk angle; screen light pulses while typing; hands peek out either side, behind the lid |
| `typewriter` | back to the viewer (no keys visible); carriage and paper step sideways and return; hands peek out either side, behind the housing |
| `pen` (alias `quill`) | the left hand (front layer) holds the quill and writes right→left on the paper; the right hand rests hidden behind the desk; an inkwell sits on the desk, and the quill rests in it while sleeping or away |

| data-side | desk scene orientation (always faces the middle of the monitor) |
|---|---|
| `right` (**default when absent**) | desk at the right of the monitor, facing left: tool on the left of the desk, buddy behind and to the right |
| `left` | full mirror: tool on the right, buddy on the left |

| data-dir | wandering direction (ignored in the desk scene) |
|---|---|
| absent | moving right: faces right. walking: left (trailing) hand on top. rushing/racing: right hand on top |
| `left` | moving left: faces left. walking: right (trailing) hand on top. rushing/racing: left hand on top |

For `walking`, `rushing` and `racing` the buddy faces the way it's travelling (lean, face offset and trailing hands). The unmirrored base art faces left, so `.lw-scene` is mirrored when `data-dir` is absent. Other wandering states (`idle`, `peeking`, `watching`) keep the old rule: `data-dir="left"` mirrors them.

### Desk-alone layer (wandering)
When the buddy leaves the desk, the desk and tool must stay where they are while the character moves. The easiest setup:
1. **At the desk:** one element, `character.svg` with `data-body="typing"` or `"sleeping"`.
2. **Wandering:** put `desk.svg` (or a second `character.svg` with `data-body="away-from-desk"`) at the desk position, give it the same `data-tool` and `data-side`, and move the character element with `walking`, `rushing`, `peeking`, `watching` and so on. The wandering states never draw the desk.
3. **Back at the desk:** remove or hide the desk element and switch the character back to `typing`, at the desk position.

Both files share the same viewBox and geometry, so the swap is pixel-aligned. In the desk scene the buddy's body centre is at (180,110) for `side=right`, or (60,110) for `side=left`; the buddy's idle position is (120,110). The 1.25 desk scale drops the rendered centre to y 94.5. The wander sprite is 150×137.5 CSS px (1.25× the 120×110 home host) so that body matches the desk body. Use these to line up the race-back.

## Colours
Set `--body` and `--outline`. `--shade` and `--hands` are **one colour derived from `--body`** in CSS: `oklch(from var(--body) …)`, with L ×0.75 (about 25% darker) and chroma ×1.8 so it stays warm. When the body's OKLCH lightness is below 0.42, the shade switches to a lighter colour (L +0.18). You can still override `--shade` or `--hands` explicitly.
For webviews without CSS relative colour support, `lwApplyColor(el, '#hex')` from `lw-color.js` sets `--body`, `--shade` and `--hands` using the same rule. `lwDeriveShade(hex)` returns only the shade. Other variables: `--desk`, `--desk-shade`, `--desk-side-dark`, `--paper`, `--paper-shade`, `--blush`, `--tool`, `--tool-shade`, `--screen`, `--ink`, `--inkwell`, `--ink-shine`, `--feather`, `--feather-shade`.
Note: on very dark bodies, choose a lighter `--outline` too, because the eyes and mouth use `--outline`.

## UI buttons
`ui-close.svg` (`.lw-ui.lw-ui-close`) and `ui-gear.svg` (`.lw-ui.lw-ui-gear`): 32×32, inline, styled in `lw-character.css`. On hover they grow and the glyph rotates; the close button turns `--ui-close-hover` and the gear `--ui-hover`. `:active` shrinks them and `:focus-visible` adds an outline. Variables: `--ui-bg`, `--ui-shade`, `--ui-glyph`, `--ui-hover`, `--ui-close-hover`, `--outline`.

## Layers / class names
```
svg.lw-char
└ g.lw-scene                 (mirrored for data-side=left in the desk scene, or data-dir=left otherwise)
  ├ g.lw-rig.lw-rig-back     hand-l (wandering), .lw-hand-backr (right hand behind body, travel states), .lw-body, .lw-back, .lw-face(.lw-eyes, .lw-mouth, .lw-blush, .lw-zzz)
  ├ g.lw-station
  │ ├ g.lw-rig.lw-rig-mid    .lw-hand-mid ×2: desk hands, always BEHIND desk + tool
  │ ├ g.lw-desk              .lw-flipx (no transform) > .lw-desk-front (the desk's back: plain panel), .lw-desk-side, .lw-desk-slab (front + side lips; no visible top since v0.8)
  │ └ g.lw-tools             .lw-tool-laptop(.lw-laptop-glow) | .lw-tool-typewriter(.lw-tw-carriage, .lw-tw-vents)
  │                          | .lw-tool-pen(.lw-pen-paper, .lw-pen-ink, .lw-inkwell, .lw-quill-rest)
  └ g.lw-rig.lw-rig-front    .lw-hand-front (pen-writing left hand with .lw-quill-art; also the on-top left hand in travel states), hand-r (wandering)
```
Hands: `.lw-hand.lw-hand-l|r > g[transform] > .lw-hand-inner`. Respects `prefers-reduced-motion`.

## Changelog
**v0.4**: taller desk (viewBox still 240×220); three writing tools behind `data-tool`; UI close/gear buttons.
Possibly breaking: (1) the old trapezoid "paper" in `.lw-desk` is gone; the default tool is now the laptop. (2) The single `.lw-rig` is now two groups (`.lw-rig-back` and `.lw-rig-front`), and `.lw-hand-l` now matches two elements, so a selector like `querySelector('.lw-rig')` only gets the back rig. (3) At the desk the body sits 18px higher (it was 14px), and the sleep pose moved up to match.
**v0.5**: desk has a solid front panel (`--desk`/`--desk-shade`); props are about 1.3–1.35× bigger (scaled around the desk centre); for laptop/typewriter the hands sit behind the tool (new `.lw-rig-mid`/`.lw-hand-mid`), while pen keeps the hand in front. The `data-*` API is unchanged. Class changes: `.lw-desk` now draws in front of the body; there's a third `.lw-rig` group; `.lw-hand-l`/`.lw-hand-r` each match up to 3 elements (only one is visible at a time); `.lw-tool` groups carry a scale `transform` attribute, so don't overwrite their `transform`.
**v0.6**: new `data-body="watching"` (alias `away`) back view (new `.lw-back` layer); works with the recolour vars and `data-dir`.
**v0.6b**: new `data-side="right|left"`. The typewriter is turned around (back faces the viewer). The pen moved to the left hand, and the unused right hand rests below the desk top. Hands are always fully behind the desk and tool (the pen hand is the exception). Class changes: new `.lw-station` wrapper (desk + mid hands + tools); `.lw-rig-mid` now sits behind `.lw-desk`; `.lw-tools` gets a CSS transform under `data-side`; the typewriter's `.lw-tw-keys` is gone and `.lw-tw-vents` is new; the quill is wrapped in `.lw-quill-flip`; new var `--paper-shade`.
**v0.6c**: the buddy sits lower behind the desk (rig `translateY(8px)` at the desk, was −18px; sleep pose +14px), so the face and upper body show above the desk. The pen paper is flatter, and the quill and left hand moved lower-left, clear of the eye. The SVG is still 240×220 and the API is unchanged.
**v0.7** (rebuilt desk scene). The seat height is kept, and the props are back to full, unsquashed size.

- New `data-body="rushing"` (hands trail behind). `racing` still works.
- `--shade` and `--hands` are derived from `--body` (OKLCH relative colour, flipping lighter for dark bodies). New `lw-color.js` with `lwApplyColor`. The shade and hands pickers were removed from the preview.
- New `data-body="away-from-desk"` and `desk.svg` for the desk-alone layer.
- Typewriter carriage direction reversed.
- Walking hand layering follows `data-dir`.
- **Breaking:** the `data-side` meaning changed from "skew the desk" to "mirror the scene" (and it now defaults to `right`). `.lw-station` no longer gets a skew transform, and `.lw-tools` no longer gets a rotate. The tools no longer use scale `transform` attributes. There's a new `.lw-scene` wrapper, which carries the mirror transforms; `data-dir` now mirrors `.lw-scene` instead of the `<svg>` element and is ignored in the desk scene. `.lw-quill` and `.lw-quill-flip` were removed: the writing quill is now `.lw-quill-art` inside `.lw-hand-front`, and the resting quill is `.lw-quill-rest`. `--shade` and `--hands` are no longer constants (they're derived from `--body`).
